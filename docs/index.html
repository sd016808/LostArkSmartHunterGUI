Smart Hunter 使用手冊

從下載安裝，到每天一鍵打完所有角色的混沌副本、樂園與地獄。第一次用照「六步驟上手」做；之後遇到狀況，翻到最下面的常見問題。

適用 Lost Ark 台版 註冊免費試用 3 天 需要 Windows 10 / 11

第一次使用安裝

  1. 下載：到 Releases 頁面 下載最新版的 SmartHunter_vX.X.X.zip。每一版改了什麼看 更新紀錄。
  2. 解壓縮：整個 zip 解壓縮到同一個資料夾，例如 D:\SmartHunter。LostArkSmartHunter.exe、所有 .dll 和 Routes 資料夾要放在一起，只拷 exe 開不起來。
  3. 安裝 ViGEmBus：到 ViGEmBus Releases 下載安裝檔安裝，裝完重開機。程式用它模擬 Xbox 搖桿來操作角色，只要裝一次。
  4. 執行：雙擊 LostArkSmartHunter.exe。Windows 會問「是否允許此 App 變更您的裝置」，按「是」。遊戲只接受系統管理員權限程式送出的按鍵，所以每次開都會問。
第一次執行跳出「Windows 已保護您的電腦」？

按「其他資訊」再按「仍要執行」。不需要另外安裝 .NET。

第一次使用註冊與登入

第一次打開會看到登入畫面。切到 註冊 (免費試用 3 天)，填 email 和密碼 (至少 8 個字)，按 註冊並開始試用 就會直接進主畫面。

  • 一台電腦只有一次免費試用。同一台電腦再註冊新帳號，帳號會建立，但要付費才能使用。
  • 記住登入：之後開程式會直接進主畫面，不用再打密碼；按右上角 登出 才會忘記。
  • 同一個帳號同時只能在一台電腦使用。在另一台電腦登入，原本那台會被登出，正在跑的任務也會停。
  • 忘記密碼：登入畫面切到 忘記密碼，填 email 按 寄驗證碼到這個 email，把信裡的 6 位數驗證碼 (15 分鐘內有效) 和新密碼填進去就好。沒收到先看垃圾信件夾。驗證碼一小時最多寄 3 次，輸錯 5 次要重寄。

第一次使用遊戲畫面設定

程式是「看」遊戲畫面來判斷現在在哪、要按什麼，所以遊戲畫面要讓它看得清楚。開始任務前確認一次，打勾會記在這個瀏覽器裡。

第一次使用遊戲內設定

下面五項是遊戲裡的設定，一定要照著調，程式才看得懂畫面、技能才打得到怪。前三項在遊戲的設定選單裡，照截圖上的分類標題找。

自動瞄準

  • 一般技能自動瞄準勾
  • 地點技能自動瞄準勾

在「額外功能」→「自動瞄準」。程式用虛擬搖桿放技能，要靠自動瞄準才會對準怪。

指定地點技能

  • 使用智能指定地點技能勾
  • 顯示指定地點技能教學不勾

在「指定地點技能設定」。勾了智能指定，地點技能會直接放出去，不會停下來等人選位置；教學不勾，才不會跳出視窗擋住畫面。

HUD 大小

  • HUD大小100%

在「UI顯示設定」。程式找按鈕和介面的位置，是照 HUD 100% 的大小量的，調大調小都會找不到。

右上角的小地圖

  • 縮放100%
  • 透明度100%

程式靠小地圖認出角色在副本裡的位置，縮放或透明度不一樣，就對不上錄好的路線。

角色列表右邊的面板

  • 混沌副本要顯示
  • 樂園(天堂)要顯示

ESC →「立即使用其他角色登入」，右邊這個面板。用面板右上角的齒輪設定要顯示的項目，「混沌副本」和「樂園(天堂)」都要出現，順序沒關係。程式從這裡讀每隻角色還剩幾次；沒顯示的話讀不到，角色會被當成沒有次數而全部跳過。

第一次使用設定角色

設定 分頁決定每日任務要打哪些角色、打哪個副本。改完按 儲存，下一次開始任務時生效，不用重開程式。

slot 是角色在列表裡的位置

遊戲裡 ESC 選單的 立即使用其他角色登入 會列出所有角色。slot 就是角色在這個列表的位置：從左到右、從上到下數，第一排是 1、2、3，第二排 4、5、6，以此類推，最多 30 隻。超過 9 隻時程式會自己捲動列表。

多個帳號可以共用同一份設定：slot 照角色最多的那個帳號填，角色比較少的帳號沒有的 slot 會自動略過。

每隻角色要打的副本

  • 下拉選 自動、涅夫塔1作戰、亞比都斯3作戰、亞比都斯2作戰 或 亞比都斯1作戰。
  • 自動：依序找 涅夫塔1 → 亞比都斯3 → 亞比都斯2 → 亞比都斯1，打第一個能進的；都不能打就只做公會簽到。
  • 混沌副本次數 100 以上 的角色才會進副本，不夠的角色直接跳過、不登入。
  • 不想打的角色按 移除；要加角色按 + 加一隻角色。
  • 公會：每隻角色一定會簽到；勾 公會簽到後順便捐贈銀幣 才會捐。
  • 打完自動關遊戲：勾了的話，所有角色處理完會從 ESC 選單關閉遊戲。中途失敗不會關。

地獄與其他設定

  • 地獄寶箱順序：打完要開哪個寶箱，照順序挑畫面上第一個有的，用「、」隔開，例如 特殊提煉、綁定金幣、融合。名稱裡有這幾個字就算符合，寫 7階段特殊提煉寶箱 就只要 7 階段的。留空 = 預設順序 (特殊提煉 > 綁定金幣 > 融合 > 天堂 > 破壞石 > 提煉輔助 > 星石 > 碎片 > 命運之石 > 能力石 > 手環)。
  • 地獄打完自動開寶箱：預設勾。不勾的話打完會停在原地、嗶兩聲提醒你自己來開寶箱，開完 (「再次挑戰」亮了) 就自動再次挑戰或換下一隻角色。
  • 地獄要打的角色：預設跟每日任務一樣；取消勾選 地獄打的角色跟上面每日混沌副本相同 就能另外設定，每隻也可以有自己的寶箱順序。
  • 角色名字白名單 (選填)：一行一個角色名字，只用來修正統計報表裡辨識錯的名字。
  • 重播停留：一般不用改。
  • 修理裝備：勾了的話每隻角色登入簽到後，會用寵物功能的「修理」把穿戴裝備修好。要有水晶光環才有寵物功能，沒有的角色會自動跳過，不影響打副本。預設不勾。
  • 一鍵每日：勾要一起打的項目 (樂園、地獄、混沌副本，預設都勾)。按 Ctrl+F6 時每隻角色只登入一次，簽到 → 樂園 → 地獄 → 混沌副本一次打完；角色用上面每日混沌副本與地獄的設定。原本的 Ctrl+F10 / F8 / F5 不受影響。
  • 釣魚：生活能量低於多少就停止釣魚 (預設 300)，釣竿技能放在技能列哪一格 (預設 R；程式按這個鍵，也看這一格有沒有亮)，以及撒網技能放在哪一格 (預設 W，不能跟釣竿同一格；不想撒網選「不使用」)。另外兩個收竿後順便做的選項：釣竿壞了自動修理工具和穿戴裝備 (預設勾；用寵物功能，要有水晶光環，沒有就不修)、生活能量低於多少時用恢復藥水補回來 (預設不勾；先用初級，用完換中級、高級)。
  • 滑鼠游標：游標擋到要辨識的畫面時程式會把它移到畫面左邊；這裡填最少隔幾秒才再檢查一次，0 = 每次截圖前都檢查 (預設)。覺得滑鼠太常被移走可以填 5 或 10，但游標擋在結算畫面的按鈕上程式會看不到通關，數字越大風險越高。

多個帳號：設定檔

玩好幾個帳號的話，每個帳號可以有自己的一份設定。主控 分頁最上面的「設定檔」下拉選單：預設是 settings.json，在右邊輸入名稱 (例如 小號) 按 新增，就會從目前這份複製出 settings_小號.json 並切過去，之後 設定 分頁改的、儲存的就是這一份。

  • 切換後下一次開始任務才生效；任務進行中不能切換、新增或刪除。
  • 每份設定檔的戰報和統計分開放：預設在 reports、stats，小號在 reports\小號、stats\小號。「開啟 reports 資料夾」開的是目前設定檔的那一層。
  • 刪除 要按兩次才會真的刪，只刪設定檔，戰報和統計留著；預設那份不能刪。上次選的設定檔下次開程式會記住。

每天使用開始任務

開好遊戲、角色站在城裡或任何安全的地方，按 主控 分頁的按鈕或快捷鍵開始。六種任務同時只能跑一種。

每日混沌副本

Ctrl+F10 或 開始 每日混沌副本
  1. 照 slot 順序切換角色，次數不到 100 的跳過
  2. 公會簽到，有勾就捐贈銀幣、修理裝備
  3. 領每週淨化任務獎勵，進混沌副本，照錄好的路線打完
  4. 全部完成會發出提示音，有勾就關遊戲
中途停掉再按一次會從頭跑：已經打過的角色次數扣掉了，會直接跳過。

樂園 (天堂)

Ctrl+F8 或 開始 樂園
  1. 跟每日任務用同一份角色；樂園次數是 0 的角色跳過
  2. 戰況板 → 樂園 → 天堂，選能打的最高階段入場
  3. 自動放技能、往怪靠過去。左上的「自動重複目前階段」開著會自動關掉，每場中間才有時間整理
  4. 每場打完：撿畫面上的「樂園的片鱗」(走過去按 G) → 穿上有藍色向上箭頭的裝備 → 材料萃取 → 按「再次挑戰」，直到「再次挑戰」不亮 (票打完)
  5. 最後把共鳴按完 (樂園遺產 → 共鳴 → 一直按「嘗試共鳴」到共鳴石不夠)，再按「離開」，換下一隻
只打樂園，不做公會簽到和混沌副本。票很多打超過 50 分鐘時，那場打完會先離開再重新入場 (片鱗掉落一小時沒撿會消失，離開副本時遊戲會自動撿起來)。材料萃取會分解道具，分解什麼是照遊戲裡的「自動分解設定」(材料萃取視窗的齒輪)：請先在遊戲裡設好，沒設定就不會分解。

地獄

Ctrl+F5 或 開始 地獄
  1. 每隻角色都會登入 (角色列表看不到地獄次數)
  2. 選鑰匙入場：綠 > 白 > 橘 > 紫 > 藍，奈落鑰匙不用
  3. 每層清怪、使用祭壇 (只放藍色鑰匙)，找互動點往下跳，綠色「孤注一擲」優先
  4. 打完照寶箱順序開一個寶箱，按「再次挑戰」繼續，沒鑰匙就換下一隻
每一場到過哪些樓層、開了什麼寶箱都會記錄下來。

釣魚

Ctrl+F7 或 開始 釣魚
  1. 先手拿釣竿站在釣點，把滑鼠游標放在要拋餌的地方，再按開始
  2. 程式按 R 拋竿，看到魚餌處的黃色驚嘆號就按 R 收竿
  3. 等太久沒上鉤會收竿重拋；任務中不會動你的滑鼠
  4. 釣到魚觸發撒網 (撒網那一格亮起來) 時會自動撒網，並自動玩按空白鍵、讓浮標待在黃色區間的小遊戲，玩完繼續釣
  5. 每一竿之後讀畫面下方的生活能量，低於設定值 (預設 300) 就停
  6. 釣竿壞了 (小地圖左邊出現紅色十字鎬) 時，收竿後會用寵物功能把工具和穿戴裝備一起修好再繼續釣；沒有水晶光環修不了就不修
  7. 設定頁有勾的話，生活能量低於你設的數字時，收竿後會打開「恢復與補充」用恢復藥水補回來：先用初級 (1,000)，用完換中級 (3,000)、高級 (5,000)，補到不低於那個數字就不用了
只認黃色驚嘆號，不看魚餌的顏色。修理和用藥水都會動到滑鼠，做完會把游標放回原本拋竿的位置。

一鍵每日

Ctrl+F6 或 開始 一鍵每日
  1. 每隻角色只登入一次：設定頁「一鍵每日」勾了的項目 (樂園、地獄、混沌副本) 都沒有次數的角色跳過
  2. 登入後先公會簽到 (有勾就捐贈銀幣、修理裝備)
  3. 樂園 → 地獄 → 混沌副本，一項一項照上面三種任務的方式打完，再換下一隻
  4. 結束時三種結果合在同一張結算表與戰報裡
角色用每日混沌副本與地獄的設定。勾了地獄的話每隻角色都會登入確認鑰匙，會比只勾樂園、混沌慢一些。

共鳴

Ctrl+F4 或 開始 共鳴
  1. 跟每日任務用同一份角色，每隻都會登入 (共鳴石有幾顆要打開共鳴視窗才知道)
  2. 戰況板 → 樂園 → 天堂分頁 → 右邊樂園遺產的「共鳴」
  3. 一直按「嘗試共鳴」，跳出「品級上升」就按確認，按到共鳴石不夠為止
  4. 關掉視窗，換下一隻
天堂已經打完、但共鳴還沒按的時候用；只按共鳴，不入場、不做公會簽到。開始時如果樂園視窗已經開著，會先幫目前這隻角色按，再換其他角色。

暫停、停止與其他操作

  • 暫停 / 繼續：任務中按 F10 (或 暫停 按鈕) 就可以自己操作角色，再按一次 F10 繼續。
  • 停止：再按一次同一個快捷鍵，或按變成紅色的 停止 … 按鈕。程式會先做完手上的動作再停，可能要等幾秒。
  • 換任務：一個任務在跑時，按另一個任務的快捷鍵不會動作，要先停掉原本的。
  • 遊戲上的標記：紅圈 = 認到的怪、箭頭 = 往哪走；地獄裡綠框 G = 綠色「孤注一擲」、黃框 W = 一般的往下跳互動點。只有視窗或無邊框模式看得到，錄影也錄不到。

Ctrl+F7開始 / 停止 釣魚

每天使用看結果

主控分頁左邊的 狀態 顯示現在在做什麼，右邊是執行紀錄。每日任務結束時 (完成、失敗或手動停止都會)，左邊會出現每隻角色的結算表，並在程式資料夾的 reports 產生一份戰報網頁，按 開啟 reports 資料夾 就找得到，用瀏覽器打開，不用網路。

戰報裡有：

  • 今日結算：每隻角色的副本、結果、時間、死亡次數、片鱗、公會簽到 / 捐贈，破本月最快會標出來
  • 近 30 天每張地圖的通關時間趨勢
  • 本月各地圖的場數、平均 / 最快 / 最慢時間
  • 死亡位置：在路線地圖上標出每次死掉的地方
  • 片鱗：每隻角色今天 / 本月出現幾個，分命運與祝福
  • 樂園：今天每隻角色打的階段與場數 (樂園任務結束時也會產生戰報)
為什麼會「逾時」？

一場副本超過 6 分鐘還沒看到結算畫面，程式會當作結束、換下一隻角色，當下的畫面存在 logs 資料夾。常見原因是滑鼠擋在結算畫面的按鈕上，或角色卡在地形。

需要幫忙時回報問題與遠端協助

送出回報

到 協助 分頁，寫下發生什麼事 (哪個任務、第幾隻角色、大概幾點)，按 送出回報。程式會把最近 7 天的執行紀錄、失敗時的截圖、設定和統計紀錄打包傳給作者。不會傳遊戲帳號密碼。

遠端協助

需要作者直接看畫面時，按 請作者遠端協助，作者會收到通知，在瀏覽器看到你整個螢幕 (不只遊戲)。

  • 預設只能看；勾 允許遙控 作者才能操作你的滑鼠鍵盤。
  • 處理完按 結束協助模式 或關掉程式，所有連線就會中斷。
  • 每次連線的時間和來源都記在 logs\remote_connections.log。

需要幫忙時常見問題

角色全部被跳過，說混沌副本次數不夠或樂園沒有次數

角色列表右邊的面板沒有顯示「混沌副本」或「樂園(天堂)」，程式讀不到剩餘次數。照 遊戲內設定 第 5 項，用面板右上角的齒輪把這兩項顯示出來。

技能常常放空，沒打到怪

檢查 遊戲內設定 的「一般技能自動瞄準」、「地點技能自動瞄準」、「使用智能指定地點技能」有沒有都勾。

按了開始沒反應，顯示「找不到 LOSTARK 視窗」

遊戲還沒開、還在讀取，或被縮到工作列了。等遊戲畫面出來、角色可以動之後再按一次。

顯示「虛擬搖桿連接失敗」

ViGEmBus 沒裝或還沒準備好。到 安裝 第 3 步裝 ViGEmBus，裝完重開機。剛開機時驅動可能晚一點才好，等一下再按主控分頁的 重試。

註冊後說「這台電腦已經用過免費試用」

一台電腦只有一次試用。帳號已經建好了，付費後就能用，續費方式見 帳號與續費。

用到一半被登出，說「此帳號已在其他地方登入」

同一個帳號在別台電腦登入了。如果不是你，請馬上用登入畫面的「忘記密碼」改密碼。

登入時說「密碼錯誤太多次，暫停登入」

密碼連續輸錯 5 次會暫停登入 15 分鐘，畫面上會寫幾點之後可以再試；暫停期間就算密碼打對也進不去，之後再連續輸錯會停更久。想不起密碼就用登入畫面的「忘記密碼」重設，重設好馬上可以登入。已經登入、正在用的程式不受影響。如果畫面說的是「這個網路位址密碼錯誤太多次」，是你所在的網路 (例如同一個手機熱點) 在 10 分鐘內猜錯太多次，等 15 分鐘再試，或換個網路。

主控分頁出現黃色的公告，或紅字說「管理員已暫停所有人的任務」、「這個版本太舊」

黃色框是作者的公告，看一下就好。紅字「管理員已暫停所有人的任務」通常是遊戲改版讓工具暫時不能用，正在跑的任務會被停掉；作者修好解除後程式會自動恢復，不用重開。紅字說「這個版本太舊」就到「帳號」分頁按「檢查更新」裝新版，正在跑的任務會讓它跑完，之後要更新才能再開始。

出現「連不上授權伺服器」

多半是網路斷了，或作者正在更新伺服器 (通常幾分鐘)。任務會照跑，30 分鐘內恢復就自動回到正常，不用做任何事；超過 30 分鐘才會回到登入畫面，網路好了再登入即可。

任務卡住不動了

按 F10 暫停，自己把角色帶到正常的地方，再按 F10 繼續；或按同一個任務的快捷鍵停止，重新開始。

再發生的話，到 協助 分頁送出回報，寫下是哪個任務、第幾隻角色、大概幾點。

主控分頁的紀錄出現「遊戲視窗不在支援範圍」

遊戲解析度不是 16:9 或小於 1920×1080。到遊戲設定改成 1920×1080 或 2560×1440 等 16:9 解析度，改完不用重開程式。

程式的字太大、視窗超出螢幕

按右上角的「－」，或按住 Ctrl 滾滑鼠滾輪縮小。視窗大小和縮放會記住，下次開一樣。

在設定頁改了東西但沒生效

改完要按 儲存。設定在開始任務時才讀，正在跑的任務不會變，下次開始才生效。

程式說有新版本，要不要更新？

建議更新。登入後程式會自己檢查，有新版會跳出更新內容；任務進行中請先停止再更新。你的設定和登入狀態不會被覆蓋。

好幾個遊戲帳號可以共用同一份設定嗎？

可以。slot 照角色最多的那個帳號填，角色比較少的帳號沒有的 slot 會自動略過，也不會出現在結算表。

需要幫忙時注意事項

使用風險

使用任何自動化工具都可能違反遊戲的服務條款，請自行評估風險，使用後果由使用者自行承擔。

  • 程式資料夾裡的 settings.json 是你的設定，logs 是執行紀錄，reports 是戰報，stats 是每場的統計紀錄。搬資料夾時整個一起搬。
  • 用設定檔分帳號時，小號的設定是 settings_小號.json，戰報和統計在 reports\小號、stats\小號。
  • 想自己用手機看電腦畫面，請用作者的另一個免費程式 SmartRemote；本程式的遠端協助只給作者排查問題用。
